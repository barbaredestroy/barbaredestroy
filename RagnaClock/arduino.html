Configurer l'ESP32 pour RagnaClock

Avant de téléverser, remplace impérativement les XXXXXXXXXXXXXXXXXX par ton SSID Wi-Fi et ton mot de passe.

1. Installer la carte ESP32
Dans le Gestionnaire de cartes, installe « esp32 by Espressif Systems », version 3.3.11.
2. Sélectionner la carte exacte
Outils → Type de carte → esp32 → ESP32S3 Dev Module
3. Installer la bibliothèque HUB75
ESP32 HUB75 LED MATRIX PANEL DMA Display — mrcodetastic
4. Installer la bibliothèque graphique
Adafruit GFX Library — Adafruit
Si Arduino propose les dépendances, accepte « Install all ».
5. Préparer puis téléverser
Remplace le SSID et le mot de passe, branche l'ESP32-S3, choisis le port puis clique sur Téléverser.
