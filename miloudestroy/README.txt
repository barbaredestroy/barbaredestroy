MILOUDESTROY — VERSION GITHUB PAGES

1. Décompressez le ZIP.
2. Envoyez index.html, style.css, script.js et le dossier images à la racine de votre dépôt GitHub.
3. Dans GitHub : Settings > Pages > Deploy from a branch > main / root.

Le site est entièrement statique : aucune installation, compilation ou commande n'est nécessaire.
